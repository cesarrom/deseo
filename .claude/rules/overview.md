# Deseo - SEO Platform Overview

## Mission
AI-powered SEO automation platform with content generation, repository optimization, and multi-CMS integration.

## Core Features
1. **AI Article Generation**: Accept any payload, generate SEO-optimized articles in AST format
2. **Repository SEO Optimization**: Monitor repos, auto-generate PRs with SEO improvements
3. **Keyword Research**: GSC integration for opportunity discovery
4. **Multi-CMS Publishing**: Strapi, WordPress, Payload support
5. **Per-Client Isolation**: Dedicated Payload CMS instances via Docker

## Target Users
- Marketing agencies
- Content teams
- SaaS companies
- Developers needing SEO automation
