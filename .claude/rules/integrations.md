# Integrations

## CMS Integrations
- **Strapi**: REST API, dynamic content type mapping
- **WordPress**: REST API, Gutenberg blocks
- **Payload**: Direct API, block-based editor
- **Generic**: Plugin system for custom CMSes

## Git Platforms
- **GitHub**: OAuth, webhooks, PR creation
- **GitLab**: OAuth, webhooks, MR creation

## Google Search Console
- OAuth 2.0 flow
- Keyword data fetching
- Performance tracking

## OpenRouter
- Model selection per client
- Streaming responses
- Token tracking

## Dokploy
- Container orchestration
- Per-client Payload instances
- Docker CLI fallback for local
