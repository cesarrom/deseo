# Design System

## Components
- shadcn/ui as base
- Lucide icons
- TailwindCSS for styling
- Dark mode support

## Patterns
- Consistent spacing (4, 8, 16, 24, 32, 48, 64)
- Typography scale
- Color palette from shadcn
- Responsive breakpoints: sm, md, lg, xl, 2xl

## File Structure
```
packages/ui/
├── components/    # React components
├── styles/        # Tailwind configs
└── hooks/         # Shared hooks
```
